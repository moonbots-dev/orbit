# Changelog

## 0.1.0 · local milestone

- Direct default import, `connect`, explicit targets and typed device groups.
- Complete frames, drawing callbacks, animation timing and bounded frame queues.
- Simulator, manual clock, input injection, raw recording and replay.
- Optional Canvas renderer and authenticated host client.
- ESM, declarations and source maps; package tested outside the workspace.
- No hardware, audio, HID or firmware adapter. Font and decoded-image operations remain unsupported.
